## What's new

### 4K playback
- 4K videos, including 4K (UHD) Blu-ray disc images, now get the PS5's hardware video decoder when it couldn't find enough memory before. Emby5 frees the decoders it isn't using for as long as the 4K video plays, and brings them back afterwards.

## Installation and updating

1. Close Emby5 completely.
2. Download **Emby5-1.3.1.zip** from the assets below, not a source-code archive.
3. Extract the ZIP to obtain the **PPSA99515/** folder.
4. Copy the complete folder into **/data/homebrew/**. For an update, merge and overwrite the existing application files.
5. Wait for the transfer to finish, then launch Emby5 and confirm **1.3.1** under **Settings > System > Installed version**.
