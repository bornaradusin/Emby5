# Emby5 theme presets

Emby5 has 32 native visual presets. **Emby5** (appended ID 31) is the
default for new settings: near-black background, dark glass panels and bright
Emby-green accent. Existing preset IDs 0 through 30 and named custom slots
remain compatible. Previously saved explicit choices are not overwritten.

Choose **Settings > System > Appearance > Themes & Colours > Theme preset**.
Select Emby5 and use Reset to selected preset defaults to remove older
colour/material overrides; Apply saves the draft. Cancel discards it.

The 31 earlier presets have refreshed, more vibrant palettes: blue glass,
cyan acrylic, purple gloss, mint outlines, warm amber, neutral light surfaces,
and deliberately distinct pixel/sketch/high-contrast designs. Coordinated
variants and accent overrides remain available. Text/focus contrast guards
remain active; colour refinement does not add new GPU blur or video backdrops.

Background has 13 choices: Theme default, Black, Dark, Light, Midnight blue,
Ocean blue, Deep teal, Forest green, Royal purple, Plum, Burgundy, Warm brown
and Slate blue. Explicit background choices win over the coordinated palette.
These affect the browsing UI, not video brightness, HDR or subtitle styling.

Button shapes, Solid/Glass material, sizes, reduced motion, spoiler settings,
four preview scenes and three named custom themes remain independent.

Thirty earlier names/designs are adapted from BlackBearReloaded's
ps5-homebrew-ui (01.000.010), copyright (C) 2026, GPL-3.0-or-later. These are
AGC-native adaptations, not the original OpenGL widgets. Attribution remains.
No additional fonts or framework assets are distributed.

The software gallery and automated contrast/geometry checks are host checks,
not proof of final shader output, colours or performance on PS5.
