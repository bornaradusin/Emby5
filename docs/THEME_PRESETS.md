# Emby5 theme presets

The existing **Glass** theme is the default and remains unchanged.
The 30 additional names are adapted from `ps5-homebrew-ui` (01.000.010),
original work copyright (C) 2026 BlackBearReloaded (GPL-3.0-or-later).
These are AGC-native color/panel adaptations, **not** the original OpenGL widget themes.
Names and colors are selectable in Settings > General > Theme. The application
retains its existing layout, controller behavior, and liquid-glass animations
where used outside panels. No third-party fonts or framework assets are copied.
